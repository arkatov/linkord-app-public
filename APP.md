# Linkord

Простое, лёгкое, минималистичное и эстетичное приложение для macOS для хранения ссылок.

- Название: `Linkord.app`
- Установщик: DMG.
- Версии: нумерация начинается с `v1.0`.

## Дизайн

- Основной макет — Desktop App в Figma. При масштабе 100% шрифт SF Pro 15 и 12 pt, заголовки карточек Apercu Pro Regular 16 pt, окно 900 × 620, исходная ширина дерева 240 pt, верхняя панель 56 pt.
- Иконка приложения: `./design/icon.png`, скругление по гайдлайнам macOS.
- Все отступы, размеры шрифтов и начертания единообразны и задаются в одном месте.
- Синюю обводку элементов при фокусе не показываем.
- Языки интерфейса: Ru и En, переключение в настройках.
- Масштаб интерфейса: ⌘+ / ⌘− меняют, ⌘0 сбрасывает (как в браузерах).

## Каталоги

- Каталог (пространство) — обычная папка на диске. Можно выбрать любой, как хранилище в Obsidian.
- По умолчанию открывается последний использованный каталог.
- При первом запуске выбрать каталог можно из главной области.
- Все изменения данных подхватываются автоматически, без ⌘R (в том числе правки файлов вне приложения).

## Боковое меню (слева)

- Состоит из папок каталога; клик по папке сворачивает/разворачивает её.
- Действия с вложенной папкой (включая переименование) — по правому клику.
- «Новая папка» в контекстном меню создаёт поле имени в дереве под выбранной папкой, без модального окна. Enter или уход из поля создаёт папку, Esc отменяет без записи на диск.
- Переименование — прямо в строке дерева, как в Finder: имя выделено, Enter или уход из поля сохраняет, Esc отменяет; без модального окна.
- Корневая папка обозначается символом `folder.fill`. Действия корневой папки доступны по правому клику. Боковая панель постоянно видна.
- Справа в каждой строке показывается число всех ссылок в ней, включая подпапки.
- Выбранная папка: нейтральный фон на всю ширину строки и имя обычного начертания. Значок папки сохраняет форму, размер и светло-зелёный цвет.
- Сортировка папок по первому символу: сначала числа, затем алфавит.

## Список ссылок

- Показывает ссылки выбранной папки и всех её подпапок; при выборе корня — все ссылки каталога.
- Сортировка выбирается в настройках: дата создания (новые сверху), дата изменения (новые сверху), алфавит (А–Я / A–Z). По умолчанию — дата создания.
- Pin/Unpin по правому клику: закреплённые карточки всегда выше остальных, включая результаты поиска. Внутри обеих групп действует выбранная сортировка; состояние закрепления хранится в TXT.
- Копирование URL, редактирование, перенос и удаление — по правому клику в любом месте карточки.

- У каждой карточки нижняя линия толщиной 1 pt. Боковые поля списка 10 pt, вертикальные отступы карточки 10 pt.

### Карточка

- Состоит из: значка ссылки, заголовка, описания, URL, пути и булавки справа только у закреплённой ссылки.
- Даты добавления и изменения в карточке не показываются; сохраняются в TXT для хранения и сортировки.
- Заголовок — крупнее остального текста, светло-зелёный; клик открывает ссылку в браузере.
- Под URL — путь к папке без имени корня каталога: названия папок нейтральные, разделители `›` серые. Для ссылок непосредственно в корне путь не показывается. Клик по пути открывает папку в Linkord и сбрасывает поиск.
- Высота карточки адаптируется к ширине окна и переносам строк, меняется при ресайзе.
- При наличии favicon отображается иконка сайта, иначе — зелёный указатель из макета. Размер значка ссылки совпадает с размером иконок карточки.

## Поиск

- Слева в панели — поле поиска с лупой, справа — кнопка добавления ссылки. Поиск занимает свободную ширину. При вводе появляются число результатов и кнопка очистки.
- Работает мгновенно, без зависаний; сразу показывает найденные карточки по всему каталогу.

## Добавление и редактирование

- Открываются в инспекторе справа (как в Keynote); список остаётся виден.
- Поля: URL, заголовок, многострочное описание — подписи над полями, пустые поля без повторяющихся подсказок; одинаковые системные поля со скруглёнными углами.
- При редактировании правки сохраняются сразу при корректном URL, список обновляется автоматически.
- При добавлении новой карточки в инспекторе есть кнопки «Сохранить» и «Отмена».
- В инспекторе виден путь от корня, как в карточках. Для новой ссылки выбор папки меняет место сохранения и сохраняет введённые значения.
- Для URL из буфера обмена или поля формы заголовок и описание подгружаются из HTML страницы. Ручной ввод имеет приоритет.
- ⌘N: добавление карточки в текущую папку; если в буфере обмена есть ссылка, она подставляется автоматически.

## Иконки

- SF Symbols.
- Иконки одного назначения имеют одинаковый видимый размер с сохранением пропорций, как в Finder.
- Цвет иконок — как в Finder, без акцентного цвета.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| ⌘N | Новая карточка в текущей папке |
| ⌘+ / ⌘− / ⌘0 | Увеличить / уменьшить / сбросить масштаб |
| ⌘Q | Выйти из приложения |
| Esc | По порядку: закрыть инспектор или всплывающее окно → очистить поле поиска |

## Хранение данных

- Всё хранится в папках и файлах формата `.txt`: понятно, просто, редактируется вне приложения.
- Одна ссылка — один `.txt`-файл с полями: URL, заголовок, описание, дата добавления, дата изменения.
- Папка каталога = папка на диске; вложенность папок = вложенность на диске.
- Для быстрой работы и поиска допускается кэш (например, SQLite с FTS5). Правила:
  - источник истины — файлы `.txt`; кэш можно удалить, он пересоберётся;
  - кэш обновляется сразу при любых изменениях (в приложении или снаружи, через отслеживание файловой системы);
  - выбор технологии — по критериям скорости, простоты и универсальности.
